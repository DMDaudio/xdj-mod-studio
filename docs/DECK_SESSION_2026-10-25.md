# Deck session — v0.9.8 checks (about 45 min)

Install from the **downloaded v0.9.8 app** (the one testers get), deck freshly
switched on, stick OUT. Mods page: tick everything incl. **Phase Meter** and
**Live Key Shift (beta)**. Untick FLAC if you want the install ~10 min shorter
(it's item 9; skip it then).

Write down for each: works / doesn't / what you saw (a phone photo helps most).

## 1. UTILITY rows (new, never on a deck)
- Hold MENU → UTILITY → scroll to the end: MODS, WAVEFORM COLOR, VINYL BRAKE
  LENGTH, HOT CUE GATE, THEME.
- WAVEFORM COLOR: push, turn to 3-BAND, push. Load a track: colours change?
- VINYL BRAKE LENGTH → 4X. VINYL BRAKE on, play, pause: slower stop?
- THEME → pick one: deck recolours (1–2 s pause is normal). Back to OFF.
- MODS → OFF: blue waveform, stock brake. → ON: your choices come back.
- Open BROWSE › MENU › MY SETTINGS: same values as UTILITY? All 5 rows there?

## 2. Phase meter (main screen AND PERFORM)
- Play a track. Main screen: grey ticks + red downbeats scroll past the white
  line in time with the music?
- Open PERFORM: the same meter at the top (no stock 4-beat boxes)?

## 3. Beat jump pads
- PERFORM › BEAT JUMP, QUANTIZE OFF: tap «4 »4 a few times, then «32 »32 «64.
  Every tap jumps?
- SLIP ON, tap a jump: plays on from where the music would have been when you
  let go? Any freeze or "stuck" feeling? (That was salvofly's report.)
- Is QUANTIZE toggling by itself while you're on the BEAT JUMP tab?

## 4. 8 hot cues
- A track with hot cues D–H set in rekordbox. PERFORM › HOT CUE, tap the HOT
  CUE tab again: pads show D E F, again G H, again A B C. Tap D: jumps there?

## 5. Live key shift — salvofly's freeze (most important)
MASTER TEMPO ON, PERFORM › KEY SHIFT:
- MP3 track: + + (two up), then RESET. Freeze / "file corrupted"?
- Same with an AIFF or WAV track, and with the tempo fader moved off 0.
- Key shifted + a beat jump or hot cue press while shifted.
- If it freezes: note exactly what you did just before, the file type and the
  message (photo). Power-cycle; that's all.

## 6. Live stems (faster mute, beta)
- A STEMS file (Track Builder makes them), PERFORM › STEMS, mute VOCALS:
  roughly how many seconds until you hear it? (was ~30 s, now hoped < 5 s)

## 7. RGB / 3-band, centre + overview
- Quick look: both waveforms coloured, also on PERFORM's strip.

## 8. Permanent UPD — only if you WANT to flash (optional, risky)
- Not needed for this session. If you do: Permanent tab, preset
  "Everything", build (boot-test runs itself), keep the official 1.15 file
  on a second stick for recovery. Then check UTILITY rows after power-on.

## 9. FLAC / Opus (if installed)
- Eject + re-insert the stick after the install, then a .flac and an .opus
  play?

Afterwards: paste the results (or photos) in chat — each "doesn't work"
becomes a 0.9.9 fix.
